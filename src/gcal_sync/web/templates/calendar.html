How mirroring works

A custom template can mirror a title and description built from {title}, {description}, and {calendar}; leave a template blank to pass that field through unchanged. Location is always included in template mode. Attendees are never copied. Event color applies in both modes; "Default" uses the destination calendar's normal color. Disabling a connection stops future syncing but does not remove Busy blocks already created.
