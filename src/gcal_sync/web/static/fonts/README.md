# Archivo webfonts

The Archivo variable webfont is downloaded into the application and served locally so
visitors' browsers do not contact an external font provider. This supports the promise
made in the application's privacy policy.

The Latin and Latin Extended WOFF2 subsets were downloaded from Google Fonts' Archivo
v25 distribution on 2026-09-19. Both files cover weights 400–900. The original font is
copyright 2020 The Archivo Project Authors and distributed under the SIL Open Font
License 1.1; see `OFL.txt`.

Source family: https://github.com/google/fonts/tree/main/ofl/archivo
