gcal-sync

Self-hosted, open-source availability sync across two or more Google Calendars.

gcal-sync keeps multiple Google Calendars showing accurate combined availability. For every real event on any configured calendar, it creates a private, content-free “Busy” placeholder on every other configured calendar. It never copies event titles, descriptions, attendees, locations, or conferencing links — only the fact that the time is blocked.

There is no hosted version of this service. You run your own instance, using your own Google Cloud project and your own OAuth credentials. Your calendar data is read and written directly between your own deployment and Google's servers — it never passes through the project maintainer or any third party.
